Este es un Devlog de demostración, para que cualquier desarrollador pueda usarlo como plantilla. Para redactar un devlog, ten en cuenta los siguientes puntos importantes:

- En el "front matter" (la parte que va antes del texto en sí), añade tu nombre, tu rol dentro del estudio o el equipo de desarrollo del juego mencionado, y la referencia a la ubicación de tu foto de perfil. Si no la sabes, ¡contacta a Marchel!
- Dentro del mismo "front matter", puedes cambiar el fondo del devlog; para ello debes señalar la ruta, o puedes usar una imagen de Imgur.
- Recuerda enviar todos los archivos multimedia del devlog en formato `.webp`, `.webm` o `.gif`. También recuerda enumerarlos en orden para reemplazarlos a la hora de subirlo (ej. `001.webp`, `002.webm`, etc.).

---

Si nunca has escrito un archivo en formato MarkDown, revisa este ejemplo breve: [Tutorial de Tutorial Markdown](https://tutorialmarkdown.com)

Si sabes usarlo, pero no recuerdas cosas específicas, checkea esta tabla:

| Elemento | Sintaxis | Ejemplo renderizado |
| :--- | :--- | :--- |
| Encabezado | `#` a `######` | Encabezado nivel 1 a 6 |
| Negrita | `**texto**` | **texto en negrita** |
| Cursiva | `*texto*` | *texto en cursiva* |
| Negrita y cursiva | `***texto***` | ***texto en ambos*** |
| Enlace | `[texto](url)` | [Enlace clicable](https://ejemplo.com) |
| Imagen | `![alt](url)` | ![Imagen incrustada](https://via.placeholder.com/50) |
| Lista desordenada | `- elemento` | • Lista con viñetas |
| Lista ordenada | `1. elemento` | 1. Lista numerada |
| Código inline | `` `código` `` | `código` |
| Bloque de código | `` ```lenguaje `` ` | (Bloque con resaltado de sintaxis) |
| Cita | `> texto` | (Bloque de cita) |
| Tabla | `\| col \| col \|` | (Tabla con filas y columnas) |
| Línea horizontal | `---` | (Separador visual) |
| Lista de tareas | `- [x] tarea` | ☑ Checkbox marcable |
| Tachado | `~~texto~~` | ~~texto tachado~~ |
